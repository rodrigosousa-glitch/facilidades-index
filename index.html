Problemas de análise dos dados

Verifique se o status no onboarding está em análise de documento no HUB. Se estiver, envie o cliente para a fila de pendência para tratativa com o atendente Wanderlei.

  • Checar a validação de documentação na CAF, se houver link disponível.
  • Realizar o cadastro das informações no HUB — por exemplo, e-mail — antes de abrir o chamado.
  • Para incidentes: Conta Bancária › Acesso PF › Criação de Conta / Falha › Grupo Solucionador: Engenharia.
