Problemas de análise dos dados

Verifique se o status no onboarding está em análise de documento no HUB. Se estiver, envie o cliente para a fila de pendência para tratativa com o atendente Wanderlei.

  • Checar a validação de documentação na CAF, se houver link disponível.
  • Realizar o cadastro das informações no HUB — por exemplo, e-mail — antes de abrir o chamado.
  • Para incidentes: Conta Bancária › Acesso PF › Criação de Conta / Falha › Grupo Solucionador: Engenharia.

Configuração necessária

O chat usa Supabase (plano gratuito). A chave anônima pode ficar no código — a proteção real vem de login + RLS.

  1. Crie um projeto em supabase.com
  2. Em SQL Editor, rode o script SQL do comentário no final desta página
  3. Em Authentication → Providers, ative Email
  4. Em Project Settings → API, copie URL e anon public key
  5. Cole em RF_CHAT_CONFIG no JavaScript do chat
Segurança: nunca compartilhe dados de clientes, senhas ou tokens neste chat. Use apenas para alinhamento interno. Prefira Slack/Teams/Discord da empresa para assuntos sensíveis.

Entrar no chat

Use um nome de usuário e uma senha. Não é necessário e-mail. Escolha um nome único na equipe.
